# Macerator Factory

## The First Step Toward Ore Duplication

The standalone [Macerator](../blocks/macerator.md) can turn one ingot into one dust and, with statistical approval, a
second. GenTech leadership found this technically impressive but insufficiently duplicative. By surrounding the Macerator
with two additional floors of corporate confidence, the **Macerator Factory** guarantees **two dust from every approved
ingot**, with the original 10% chance to produce one additional bonus dust.

The factory is therefore the first step toward ore duplication: one refined resource enters, two processable resources
leave, and Accounting is politely asked not to examine the conservation of mass until after quarterly reporting.

## Construction Requirements

Before substituting [Hatches](../blocks/hatches.md), construct the 3×3×3 factory shown above using:

* **1 Macerator** — controller, operator interface, and designated destroyer of material cohesion.
* **8 Machine Frames** — the lower structural ring.
* **8 matching middle-ring blocks** — use Machine Frames for 1× speed or one uniform Factory Matrix tier for an upgrade.
* **9 Machine Casings** — the upper structural layer.
* **1 block of air** — the center of the matrix ring must remain empty.

The air block is mandatory. Filling the center with equipment, storage, raw material, or an employee conducting a shortcut
study prevents the factory from forming.

> **GENTECH MASS-CREATION NOTICE:** The empty center is not where the additional dust comes from. This remains the official
> explanation pending a more marketable explanation.

## Duplication Performance

While the factory is formed, every supported recipe produces:

| Output Route | Factory Result |
| --- | --- |
| Primary Output | 2 guaranteed dust |
| Bonus Output | Independent 10% chance of 1 additional dust |
| Total Per Ingot | 2 dust, or 3 when Probability cooperates |

Only the guaranteed primary output is doubled. The chance output remains one additional dust at 10%; installing faster
matrices does not intimidate Probability into improving these terms.

## Hatch Integration

Eligible Machine Frame and Machine Casing positions may be replaced with up to one of each supported hatch:

* **Item Input Hatch** — inserts approved ingots into the factory.
* **Item Output Hatch** — extracts both guaranteed and bonus dust outputs.
* **Power Hatch** — supplies energy to the factory.
* **Network Hatch** — exposes assigned item services directly to the Machine Network.

When the structure forms, direct controller connections are disabled and side configuration is locked. Install a Power
Hatch for sustained operation, then provide item hatches or a Network Hatch for automation. A sealed factory without
external access remains structurally valid and operationally decorative.

## Matrix Performance

| Middle-Ring Material | Processing Speed |
| --- | ---: |
| Machine Frame | 1× |
| Iron Core Matrix | 1.25× |
| Steel Core Matrix | 2× |
| Titanium Core Matrix | 4× |
| Tungsten Core Matrix | 32× |
| Quantum Core Matrix | 64× |

All eight middle-ring blocks must match. Mixed matrix tiers invalidate the structure because the Macerator can pulverize
metal, not resolve disagreements between incompatible performance targets.

Faster matrices reduce processing time without reducing the recipe's total energy cost. The same energy is consumed over
fewer ticks, so higher tiers demand a faster power supply. The doubled primary output requires no additional recipe energy,
having already been paid for through construction costs and an exciting reinterpretation of physics.
