# Wrench

## Calibrated Rotational Encouragement

GenTech engineers discovered that machinery installed backward rarely becomes forward through shouting, performance
reviews, or waiting for it to recognize the problem independently. The **Wrench** provides a more direct solution by
converting a small amount of employee wrist movement into immediate mechanical compliance.

The Wrench has **143 durability** and is recognized by the shared NeoForge wrench standard. Other properly tagged wrenches
may therefore perform the same interactions. GenTech has approved this unexpected compatibility under the official term
**begrudging interoperability**.

## Approved Field Procedures

| Employee Action | Equipment Response |
| --- | --- |
| Right-click a rotatable, wrenchable block | Advance the block to its next supported orientation |
| Crouch-right-click a wrenchable block | Dismantle the block using normal block-breaking rules |

Successful rotation consumes **1 durability**. If the targeted block cannot rotate or its orientation does not change,
the Wrench performs no work and submits no durability expense.

Machine inputs, outputs, network ports, and other configured faces are defined relative to the machine. Rotating a machine
changes where those faces point in the world, so inspect connected cables and automation afterward instead of assuming the
infrastructure understood the creative direction.

> **GENTECH DISMANTLING NOTICE:** Crouch-right-clicking is not an alternate form of inspection. It is a request to remove
> the targeted block. Normal harvesting permissions and drop requirements still apply, even when the request is made with
> professional confidence.

## Reusable Tooling

When an approved crafting procedure uses the Wrench as a tool, the Wrench is returned with durability consumed rather
than being incorporated into the finished product. GenTech reached this design decision after an early production run
embedded an entire wrench inside every machine casing and described the result as “premium reinforced construction.”

Inspect the durability bar before beginning installation, reorientation, or dismantling work. A Wrench with one remaining
use is still operational; it is simply participating in a very short-term assignment.

> **GENTECH TOOL SAFETY NOTICE:** The Wrench is designed for machinery. Using it to reorient coworkers may produce no
> rotation, one disciplinary report, and several newly documented limits on employee-tool interaction.

GenTech congratulates you on receiving the authority to correct machinery one quarter-turn at a time.
