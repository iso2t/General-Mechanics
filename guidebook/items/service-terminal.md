# Service Terminal

## Orientation Is Now Portable

The **Service Terminal** is GenTech's approved employee-orientation device. Right-click while holding the terminal and not
targeting a block to open this guidebook, providing immediate access to operating procedures, equipment specifications,
and safety notices that previous personnel strongly recommend reading beforehand.

The terminal contains no loose pages, requires no shelf space, and cannot be closed dramatically during a disagreement
with the documentation.

## Smart Network Diagnostics

Due to ongoing developments in smart technology, GenTech scientists discovered that the Service Terminal can also inspect
a Machine Network. This functionality was not part of the original orientation budget and has therefore been classified
as complimentary innovation.

To inspect a network, **crouch and right-click a network-enabled block** with the Service Terminal. The terminal traces the
connected network and reports:

* The total number of connected non-cable network blocks.
* Each block's registry ID and coordinates.
* The network services registered by each block.
* Any endpoints exposed through that block.

Cables are used while tracing the network but are omitted from the final equipment list. GenTech determined that listing
every segment of cable was less diagnostic and more autobiographical.

| Approved Action | Result |
| --- | --- |
| Right-click without targeting a block | Open the GenTech Guidebook |
| Crouch-right-click a network-enabled block | Display that network's diagnostic report |

> **GENTECH SERVICE NOTICE:** The terminal identifies network conditions; it does not repair them. Discovering that every
> machine is connected incorrectly represents a successful diagnostic outcome.

GenTech congratulates the Smart Technology Division on making the instruction manual judgmental. Pretty nifty.
