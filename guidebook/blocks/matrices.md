# Factory Matrices

## Accelerated Productivity, Compressed Responsibility

Early GenTech factories processed materials at a rate researchers classified as “technically progressing.” Rather than
wait, the Advanced Impatience Division developed **Factory Matrices**: specialized core blocks that increase the processing
speed of compatible multiblock factories.

Install Factory Matrices in every designated matrix position when constructing the multiblock. All matrices within the
same factory must be the **same tier**. Mixing tiers does not average their performance; it produces an invalid structure
and a valuable lesson about teamwork.

## Approved Performance Tiers

| Matrix | Processing Speed | GenTech Classification |
| --- | ---: | --- |
| Iron Core Matrix | 1.25× | Patiently improved |
| Steel Core Matrix | 2× | Twice the progress, same number of meetings |
| Titanium Core Matrix | 4× | Management-visible acceleration |
| Tungsten Core Matrix | 32× | Results before the paperwork is ready |
| Quantum Core Matrix | 64× | Causality pending departmental approval |

Factory Matrices reduce processing time, but they do not reduce the total energy required for a job. Faster processing
delivers that energy over a shorter period, so ensure your power infrastructure can support the selected tier. A 64×
factory connected to an aspirational power supply remains an expensive arrangement of stationary blocks.

> **GENTECH UNIFORMITY NOTICE:** All matrix blocks in one factory must match. Individuality is encouraged in personnel,
> provided it does not occur inside the machine core.

Quantum Core Matrices have not been shown to make nearby employees 64 times more productive. Further employee-based
testing was discontinued after the volunteers began submitting their reports before the experiments were assigned.
